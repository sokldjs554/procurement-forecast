## 무엇을 시작했는가

**실제 모델 출력의 후속 관측**을 시작할 원본을 고정했다. 9건이 모두 올바른 신규 조달
예측이라는 뜻은 아니다. 제목이 모호한 항목, 완료 사업 언급, 지원사업,
다른 사업 금액의 혼입 등 추출 품질 문제가 남는다. 같은 자료 회귀 평가는 1/20 제목
일치이며 그 1건도 분류·금액 오류가 있다. 실패 항목도 임의로 빼지 않고 보존한다.

2025년 12월 회의록을 2026년 9월에 늦게 처리한 자료다. 회의일을 예측일 또는
공식 공개일로 바꾸지 않는다. 동결 이전에 이미 공고됐는지 전수 확인하지 못했으므로
초기 observations는 coverage/outcomes가 비어 있다. 검색에서 못 찾았다는 이유로
음성 또는 완전 수집으로 표시하지 않는다.

## 관측 규칙

1. 이 최초 스냅샷과 해시는 수정하지 않는다. 새 관측은 날짜별 새 파일로 보존한다.
2. 서산시 공식 계약·입찰 게시판, 나라장터 공식 공고, 필요하면 공식 첨부문서를 확인한다.
   기관·사업 범위·공고번호가 확인돼야 대응하며 제목 키워드만 같은 사례는 보류한다.
3. 실제 공개일, 확인 시각, 원문 URL/해시와 대응 판단 근거를 기록한다.
   동결일 이전/당일 공고는 미래 적중에서 제외한다.
4. 예측 9건 모두를 관측 대상에 유지한다. 모호한 제목·기존 완료 사업·중복 가능성은
   별도 검토 기록으로 남기며 좋은 결과만 골라 분모를 만들지 않는다.
5. 540일이 실제로 지나고 프로젝트별 완전한 관측 범위를 입증할 때만 비율을 계산한다.
   불완전한 공개 검색은 complete=false 또는 coverage 미확인으로 남긴다.
6. 매주 무료 공개 자료를 점검한다. 자동화의 실행 실패·접근 제한도 기록하고,
   접근 실패를 사업 미발주로 해석하지 않는다. 상시 백엔드 운영과는 별개다.

초기 검색은 `screening-initial.json`에 기록했다. 공식 입찰 공고와 완전 대응한 결과가
없어 성공/실패 라벨을 추가하지 않았다. 독립 전문가 검토도 아직 이루어지지 않았다.
