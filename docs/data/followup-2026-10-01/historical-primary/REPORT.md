# 강남구 2025년 예산사업 3건: 공식 자료 사후 검토

## 입력 자료와 날짜

[의회 예산 심사보고서](https://www.gncouncil.go.kr/attach/council_text/323/323_3_20.pdf)를 다시 내려받아 보관했다. 6,774,892바이트 PDF는 기존 보관본과 바이트 단위로 동일하다.

- PDF SHA-256: `f6855d4b4fc8cc4af8755d2e4e8be27e752ee9fcfe03d8b90a1424b9069d9cd2`
- `pdftotext -layout` 결과 SHA-256: `62717606686014286f91f41920349a6ba6f897923feaf93b6f3afb9492d7411c`. 기존 전체 문서 재생 입력과 동일하다.
- 보고서 날짜는 2024-12-17. PDF 생성·수정 메타데이터는 2024-12-19 08:41:47 UTC, 현재 HTTP Last-Modified는 같은 날 08:47:35 UTC다.
- [의안 432 기록](https://www.gncouncil.go.kr/kr/billview.do?uid=3450)은 2024-11-04 제출, 12-17 예결위 의결, 12-19 본회의 수정가결을 표시한다. 이 날짜들은 파일의 최초 공개일을 입증하지 않는다.

**원문이 실제로 공개된 최초 날짜는 미확인이다.** 문서 날짜, PDF 생성일, HTTP Last-Modified를 공개일로 대입하지 않았다. 세 사업의 금액도 이 심사보고서의 예산안 금액이며, 최종 확정 세부 예산·입찰 예정가격·낙찰금액으로 전환하지 않았다.

별도 경로인 [강남구 예산 게시판](https://www.gangnam.go.kr/board/B_000742/list.do?mid=ID05_050302&pgno=2)은 **2025년 강남구 예산서, 2025-01-21 게시**를 표시한다. 이것은 다른 자료의 공개 기록이다. 첨부·미리보기 경로 `/file/*`가 구청 robots에서 수집 제외돼 있어 원문은 받지 않았다. 동일한 세 사업의 수록 여부와 기존 PDF와의 내용 일치를 확인하지 못했으므로, 1월 21일을 기존 입력의 공개일로 대체하거나 이 날짜로 선행 기간을 계산하지 않았다.

## 사업 범위와 후속 자료

### 문화센터: 양쪽 대상지 확인, 완료 판정 보류

[세곡도서관 안내](https://library.gangnam.go.kr/sklib/20001/bbsPostDetail.do?postIdx=58938)는 2025-08-12 게시됐으며 리모델링 예정 기간을 9월 1일~11월 30일, 화장실 공사는 9월 22일~11월 21일로 안내한다.

새로 확인한 [신사 주민도서관 안내](https://library.gangnam.go.kr/small/20007/bbsPostDetail.do?postIdx=58742)는 신사동복합문화센터 **5·6층**을 특정한다. 표시 작성일은 2025-07-21이고, 현재 내용은 **변경된 일정**으로 공사 9월 29일~12월 31일, 휴관 2026년 1월 2일까지를 안내한다. 수정 시각은 없어 현재 일정이 7월 21일에 공개됐다고 볼 수 없다.

추가로 [신사동 주민센터의 2025-12-23 게시물](https://www.gangnam.go.kr/center/board/B_000282/1105020/view.do?mid=MC150301&office=3220040)과 원본 포스터를 보관·시각 확인했다. 재개관 예고는 **2026-01-05 10:00, 주민센터 5층 도서관**이다. 이는 앞선 휴관 안내에 이어지는 공식 자료지만 실제 재개관 확인이나 모든 층의 준공 증명은 아니다. 예고된 재개관 시점도 2025년 범위 밖이다.

이차 입찰 색인의 세곡 건축·기계 `R25BK00985683-000`, 전기 `R25BK00986354-000`, 화장실 `R25BK01008684-000`, 신사 건축·기계 `R25BK01034655-000`은 후보로만 남겼다. 어느 한 공고가 두 대상지와 감리 등을 포괄하는 전체 예산사업을 대표한다고 보지 않았다. 발견된 공고 금액을 합산해 집행액을 만들지도 않았다.

### 보안등: 대상 지역의 설치 보고

[구청 보도자료](https://www.gangnam.go.kr/board/B_000031/1074583/view.do?mid=ID01_0313)는 일원1동 대청공원 주변 287개 설치를 보고한다. **713개는 일원1동·신사동·삼성2동 합계**, 3,209개는 구 전체 운영 수량이다. 대상지와 사업 유형은 일치하지만 이 자료에는 원입찰·계약금액·정확한 준공일이 없다.

### 펌프: 유사 사업을 연결하지 않음

원래 범위는 노후 간이빗물펌프장의 신규 고도화로 **RTU PANEL 제작·설치 1면 등**이다. [2025-11-24 의회 감사 회의록](https://www.gncouncil.go.kr/viewer/minutes.do?uid=8965)에는 원격감시제어시스템의 약 1억3300만원·7개월 유지관리 용역이 논의된다. 이것은 신규 RTU 개량과의 연결 근거가 없어 별도 사업으로 남겼다.

회의에 연결된 [치수과 주요 업무보고 원문](https://www.gncouncil.go.kr/attach/minutes/BO/apdx/09/a00017549.pdf)도 보관했다. 10쪽의 선별된 주요 사업 보고에서 목표 사업은 확인하지 못했다. 이 문서는 모든 발주를 열거하는 대장이 아니므로 누락을 미발주 증거로 쓰지 않았다. 5500만원의 별도 예산사업인 스마트 수방 알리미 웹사이트도 RTU 사업 실적으로 연결하지 않았다.

## 방법과 한계

검토 범위는 2025 회계연도다. 2026년에 확인한 게시물과 현재 수정된 페이지는 수집 시점과 게시·행사 시점을 각각 기록했다. 이 범위 설정은 사후 검토용이며 사전 등록된 예측 실험으로 주장하지 않는다.

최종 판정은 `historical-full-source-replay-v10.json`을 참조한다. 2026-10-01 01:21:09 UTC 실행, 코드 `da5fdb98cca25ddedbd0f568a8c6027f33b71854`, heuristic-v10, 473개 청크 전체 분류, 문서 전체 54개 신호의 오프라인 재생이다. 후속 결과를 추출기에 입력하지 않았다는 실행 기록을 참조했다. 앞선 v9는 세 사업 중 조명·펌프만 검토 대기로 추출했고 문화센터는 놓쳤다. v10의 폼피드 경계 처리 수정 후 문화센터가 승인 상태로 추가됐다. 이 비교도 이미 본 자료에서의 개발 결과이며 독립적인 검증은 아니다. 현재 코드로 재생했으므로 2024년에 실제로 한 예측으로 해석하지 않는다. 이 증거 검토 작업은 생산 코드·DB를 변경하지 않았다.

공식 의회·구청·도서관 HTML, PDF와 포스터를 보관했다. 수집은 공개 경로의 개별 요청으로 수행했으며 자동 수집 제외 경로를 우회하지 않았다. 구청 공고 제목 검색 `원격`, `스마트보안등`, `복합문화센터`와 공식 계약 메뉴, G2B 직접 링크, 예산 게시판, 의회 감사자료, 검색 엔진 두 종류를 확인했다. 검색 경로는 `search-log.json`에 남겼다.

현재 구청 계약 메뉴는 서울계약마당과 나라장터로 이동한다. 서울계약마당 robots는 관련 계약·발주계획 경로를 제외한다. G2B 직접 링크·robots 접근은 게이트웨이 오류·시간 초과로 원문을 확보하지 못했다. 옛 구청 opendoc 후보 경로는 404였다. 검색의 불완전성을 그대로 남겼으며, 검색 누락을 음성 정답으로 바꾸지 않았다.

**발주 정확도나 선행 일수 산출에 남은 요건:** 동일 범위의 공식 원입찰·계약 기록, 검증 가능한 역사적 입력 공개 시점, 해당 기간의 충분한 결과 모집단. 이번 자료가 입증하는 것은 위 표의 문서 추출 상태와 공식 후속 활동이며, 그 요건의 충족을 주장하지 않는다.

## 재현

저장소 루트에서 다음을 실행하면 네트워크·DB 접근 없이 결과와 매니페스트를 재생성하고 모든 성공 응답 원문의 SHA-256을 검사한다.

```sh
python docs/data/followup-2026-10-01/historical-primary/build_findings.py
```

`*.html`, `*.pdf`, 포스터는 원본 바이트다. `*.txt`는 파싱 결과다. 세 초기 robots 스냅샷은 접근일만 기록됐고 정확한 시각은 없다. 응답의 Set-Cookie 값은 메타데이터에서 제외했다. 실패한 초기 PDF 조회 응답도 남겼으며 파일명 확장자가 `.json`이어도 내용은 오류 HTML인 경우가 있어 매니페스트에서 구분했다.
