# 운영 반영 및 한계 보완의 완료 기준

2026-09-29. 사용자 요청: 기존 포트폴리오의 한계를 보완하고 실제 운영에 반영한다.

1. 원문과 다른 확정·계획 발언을 검토 대상으로 돌린다. 부정·조건·질문·인용과 집행부 발언을 구별하며, 규칙으로 모든 한국어 의미를 해석한다고 주장하지 않는다.
2. 연결은 기관·공고 식별자 충돌과 복수 참조의 모호함을 확인한다. 상위 12개 검색에서 유효 후보가 누락되는 문제를 없앤다. 검토에서 거절되거나 잠정인 근거는 요약·예측에 기여하지 않는다.
3. 기존 자료의 재검증은 원문만 읽는 dry-run부터 시작한다. 같은 데이터·범위의 digest가 있어야 적용한다. 식별자·검토·피드백·알림·브리프 기록을 보존하며 실제 알림과 유료 API를 호출하지 않는다.
4. 사람의 검토 결과가 연결·요약·기존 추천에 같은 트랜잭션으로 반영되어야 한다. 검토된 문서를 재추출하여 기록을 삭제하는 작업은 명시적으로 거절한다.
5. 배포 완료는 지정 환경의 서비스 생성, 비밀값 설정, 마이그레이션, 실제 상태 확인과 API 경유 응답의 증거가 있어야 한다. 현재 Render My workspace에는 이 프로젝트의 서비스/DB가 없다. 타 프로젝트의 자원을 재사용하지 않는다.
6. 실데이터 정확도, 전 구간 시계열 재현, 사업 1:N 계약 모델, 장기 전환율, 전국 수집 범위, 법률 검토는 별도 검증 항목이다. 합성 평가·설정 파일·규칙 보강으로 해결됐다고 표시하지 않는다. 새 모델 도입은 기존 정답을 조용히 바꾸지 않고 별도 설계와 이행 검증을 거친다.

제약: 추출·연결 P/R ≥ 0.95 유지. 원문 grounding 우회 금지. robots/속도 제한 준수. 유료 LLM 실행은 키와 예산 승인이 있어야 한다. 비밀값을 커밋하지 않는다. 날짜는 app.clock 사용. 운영 데이터 삭제·전체 재생성을 하지 않는다.
